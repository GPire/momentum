## 🧠 PARTE 1: NEUROPSICOLOGIA DEL DENARO & MOMENTUM

### Il neurotransmettitore dell'app: DOPAMINA ANTI-FOMO

**Insight psicologico fondamentale**: 
Le app fintech (Revolut, Wise, Copilot Money) controllano il dopamina tramite:
1. **Gamification** (badges, streak, achievements) → release intermittente
2. **Feedback istantaneo** (transazione confermata, card rossa=spesa) → reinforcement loop
3. **Social proof** (vedi i tuoi amici spendono meno di te) → FOMO attivato

**Il problema**: Questo è REGRESSIVO. Crea dipendenza superficiale, non engagement consapevole.

**MOMENTUM: Anti-FOMO dopamina** (dopamina del CONTROLLO, non della dipendenza):

```
Revolut/Wise dopamina:          Momentum dopamina:
✗ Vedi saldo alto              ✓ Vedi saldo PREVEDIBILE
✗ Upgrade tier = premessa     ✓ Controllo = realizzazione
✗ Streak = pressione          ✓ Pattern riconosciuto = comfort
✗ FOMO streak loss            ✓ Masterizzazione progressiva
```

## 🦠 PARTE 2: VIRALITÀ STRUTTURATA (Epidemiologia del contagio)

### The Viral Coefficient (k) Formula

```
k = (new_invites_per_user) × (invite_to_signup_rate) × (signup_to_retained_rate)

Momentum target:
  k > 1.5 = every user invites 1.5+ others
  
Breakdown:
  - invites_per_user: "Dividi spese" feature → 3-5 invites/month/active user
  - invite_to_signup: link preview + FOMO-free copy → 35% clickthrough
  - signup_to_retained: instant value (bootstrap istantaneo) → 45% D1 retention
  
  k = 4 invites × 0.35 conversion × 0.45 retention = 0.63
  ⚠️ PROBLEMA: k < 1 = non è virale ancora
```

### Il problema: "Dividi spese" è una **feature isolata**, non un **loop virale sistemico**

**Soluzione**: RIPROGETTARE il flusso per intrappolare la viralità in 5 momenti del journey:

#### MOMENT 1: ONBOARDING (The Induction Point)
```

  - "Quanti soldi" = salience (dati personali > generici)
```
